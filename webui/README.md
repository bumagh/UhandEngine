# UhandEngine WebUI

AI友好的游戏开发Web界面，支持与AI协作开发游戏。

## 功能

- **项目浏览器**: 浏览和编辑项目文件
- **AI助手**: 与AI对话，获取代码生成和调试帮助
- **代码编辑器**: 集成Monaco编辑器，支持语法高亮
- **场景编辑器**: 可视化编辑游戏场景（计划中）
- **资源管理器**: 管理游戏资源（计划中）
- **调试器**: 运行时调试和性能分析（计划中）

## 安装

```bash
cd webui
npm install
```

## 运行

```bash
npm run dev
```

WebUI将在 http://localhost:3000 启动

## 构建

```bash
npm run build
```

## 技术栈

- **前端**: React + TypeScript
- **UI库**: TailwindCSS + Lucide Icons
- **代码编辑器**: Monaco Editor
- **状态管理**: Zustand
- **构建工具**: Vite

## AI工作流

WebUI设计为AI友好的开发环境：

1. **对话式开发**: 通过自然语言描述需求，AI生成代码
2. **结构化查询**: AI可以查询项目结构和运行时状态
3. **代码生成**: AI基于类型反射系统生成正确的代码
4. **实时协作**: AI和人类开发者实时协作
